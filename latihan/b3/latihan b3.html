B.1 formulir (form)

atribut nilai keterangan
action URL menentukan URL tujuan data dikirimkan/sumbit
method get/post GET: data terlihat di url (untuk pencarian). POST: data tersembunyi (untuk login)
enctype multipart/form-data wajib ditambahkan jika form memiliki input file upload

struktur dasar formulir

formulir terdiri dari tag pembuka <form> dan tag penutup </form>

didalam tag <form> terdapat elemen input, textarea, select, button, dsb

elemen input memiliki atribut type yang menentukan jenis input

contoh :

<form action="proses.php" method="post">
<!-- elemen input di letakkan di sini -->
    <input type="text" name="nama">

    <input type="submit" value="kirim">
</form>

B.2 elemen input dan sejenisnya

1. Formulir Tipe Input

type="text": Kotak teks satu baris.
type="password": Kotak teks dengan karakter tersembunyi.
type="email": Kotak teks + validasi format email.
type="number": Kotak angka dengan tombol naik/turun.
type="tel": Kotak teks untuk nomor telepon.
type="date": Pemilih tanggal.
type="time": Pemilih waktu.
type="url": Kotak teks + validasi format URL.
type="radio": Tombol bulat (pilih satu).
type="checkbox": Kotak centang (bisa pilih banyak).
type="file": Tombol pilih file.
type="range": Slider geser.
type="color": Pemilih warna.
Elemen Formulir Tambahan
<textarea>: Kotak teks multi-baris.
<select> & <optgroup>: Dropdown menu berserta pengelompokan opsi.
<datalist>: Memberikan saran autocomplete pada input text.

atribut-atribut penting pada elemen <input>:

  • name : nama field digunakan server untuk mengidentifikasi data yang terkirim
  • value : penghubung dengan label (via atribut for pada <label>)
  • placeholder : teks petunjuk yang tampil saat input masih kosong
  • required : menandakan input wajib diisi sebelum form disubmit
  • disabled : menonaktifkan input sehingga tidak dapat diubah atau diklik
  • readonly : membuat input hanya bisa dibaca, tidak bisa diubah
  • min/max : batas minimum dan maximum untuk input angka atau tanggal
  • maxlength : batas maksimum jumlah karakter yang dapat diketik

Tabel Keterangan Elemen

Elemen Fungsi Keterangan Penting
<label> Memberikan keterangan pada elemen input Hubungkan ke input menggunakan atribut for yang nilainya sama dengan id input — meningkatkan aksesibilitas
<textarea> Kotak teks multi-baris Gunakan atribut rows dan cols untuk mengatur ukuran. Berbeda dengan <input>, <textarea> punya tag pembuka dan penutup
<select> Membuat dropdown / menu pilihan Setiap pilihan dibuat dengan tag <option>. Tambahkan atribut multiple untuk pilihan ganda
<optgroup> Mengelompokkan opsi dalam dropdown Gunakan atribut label untuk memberi nama grup
<fieldset> Mengelompokkan elemen form terkait Gunakan bersama <legend> untuk memberi judul pada kelompok
<datalist> Memberi saran/autocomplete pada input text Hubungkan dengan input menggunakan atribut list
