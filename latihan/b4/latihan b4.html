BAB 4

Pengantar CSS Dan Dasar Styling


A. Tujuan pembelajaran

Setelah menyelesaikan kegiatan BAB ini, peserta didik diharapkan mampu:

  • Menjelaskan konsep fungsi CSS dalam pembangunan halaman web
  • Membedakan konsep tiga cara penulisan CSS: inline, internal, dan external
  • Menggunakan selector CSS dasar (element, class, dan id) untuk menarget elemen yang tepat
  • Menerapkan properti CSS unntuk mengatur tampilan teks, warna, dan latar belakang
  • Memahami dan menggunakan berbagai satuan (unit) CSS dengan benar

B. Materi ringkas

B.1 Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang di gunakan untuk mengatur untuk tampilan dan gaya elemen-elemen HTML. jika HTML adalah kerangka/struktur bangunan, maka CSS adalah cat, dekorasi, dan tata letak ruangannya.

Tanpa CSS : Halaman web hanya menampilakn teks dan elemen polos tampa warna, font, atau tata letak. Dengan CSS : Halaman web memiliki warna, tipografi, layout, dan animasi dan tampilan yang menarik.
Cascading artinya aturan CSS diterapkan secaara berrtingkat - jika ada konflik, aturan yang lebih spesifik atau yang di tulis terakhir akan diutamakan.

B.2 Tiga Cara Menulis CSS

Cara Lokasi Penulisan Kelebihan kekurangan
Inline Di dalam elemen HTML menggunakan atribut style Mudah digunakan untuk styling cepat dan spesifik Sulit di pelihara, tidak bisa di gunakan ulang, mencampur HTML & CSS
Internal Di dalam tag <style> di bagian <head> dokumen HTML Cocok untuk 1 halamanm tidak butuh file tamabahan Tidak bisa di gunakan di halaman lain
External Di dalam file CSS terpisah yang di hubungkan ke dokumen HTML Mudah di pelihara, bisa di gunakan ulang, memisahkan HTML & CSS Butuh file tambahan, perlu koneksi untuk memuat file CSS

Urutan Prioritas CSS (dari yang paling tinggi ke paling rendah):

  1. Inline CSS -Prioritas tertinggi, selalu menimpa aturan lain
  2. Internal CSS -Menimpa CSS eksternal jika ditulis setelahnya
  3. External CSS -Berlaku global untuk seluruh halaman yang menautkannya
  4. Browser Default -Gaya bawaan browser (paling rendah prioritasnya)

Rekomendasi Gunakan CSS Eksternal untuk proyek nyata agar kode lebih terorganisir


B.3 Selector CSS Dasar

Selector menentukan elemen HTML mana yang akan diberi gaya CSS.

Selector Sintaks Contoh Keterangan
Elemen nama-tag p { color: red; } Menargetkan semua elemen dengan tag tersebut
Class .nama-class .merah { background-color: red; } Menargetkan elemen yang memiliki class tersebut
ID #nama-id #header { font-size: 24px; } Menargetkan satu elemen unik dengan ID tersebut
Universal * * { margin: 0; padding: 0; } Menargetkan semua elemen di halaman
Grouping tag1, tag2 p, h1 { color: blue; } Menerapkan gaya yang sama ke beberapa selector sekaligus
Descendant induk anak div p { font-size: 14px; } menargetkan <p> yang berada di dalam elemen <div>
Pseudo-class selector:pseudo-class a:hover { color: green; } Menargetkan elemen pada kondisi tertentu (hover, focus, dll)

Perbedaan Class vs ID :

Class(.nama) : Bisa di gunakan pada BANYAK elemen berbeda dalam satu halaman.
Satu elemen juga bisa memiliki lebih dari satu class.
Contoh: <p class="merah">
ID(#nama) : Hanya bisa di gunakan pada SATU elemen unik dalam satu halaman.
Biasanya untuk elemen utama sepeerti #header, #footer, #main, dll.
Juga dipakai untuk tautan anchor(#bagian)

B.4 Properti CSS untuk teks

Properti Contoh Nilai Fungasi
color red, #ff0000, rgb(255, 0, 0) Mengatur warna teks
font-family Arial, Times New Roman, serif Mengatur jenis font teks
font-size 12px, 1em, 100% Mengatur ukuran font teks
font-weight normal, bold, 700 Mengatur ketebalan font teks
font-style normal, italic, oblique gaya font teks (miring atau normal)
text-align left/right/center/justify Perantara teks
text-decoration none, underline, line-through Mengatur dekorasi teks (garis bawah, coret, dll)
text-transform uppercase, lowercase, capitalize Mengatur kapitalisasi teks
line-height 1.5, 150%, 2em Mengatur jarak antar baris teks
letter-spacing normal, 2px, 0.1em Mengatur jarak antar huruf
word-spacing normal, 4px, 0.2em Mengatur jarak antar kata
text-shadow none, 2px 2px 4px rgba(0, 0, 0, 0.5) Mengatur bayangan teks
text-indent 2em, 20px indentasi baris pertama teks
white-space normal, nowrap, pre teks di bungkus dan spasi di tangani

B.5 Penulisan Warna di CSS

CSS mendukung beberapa format penulisan warna:

Format Contoh Keterangan
Nama Warna red, blue, green Hanya tersedia ~140 warna standar
Hexadecimal #ff0000, #00ff00, #0000ff Format paling umum -6 digit heksadesimal (merah, hijau, biru)
RGB rgb(255, 0, 0), rgb(0, 255, 0), rgb(0, 0, 255) Menentukan warna dengan nilai merah, hijau, biru (0-255)
RGBA rgba(255, 0, 0, 0.5) Seperti RGB, tapi dengan nilai alpha (transparansi) 0-1
HSL hsl(0, 100%, 50%) Menentukan warna dengan hue, saturation, lightness
HSLA hsla(0, 100%, 50%, 0.5) Seperti HSL, tapi dengan nilai alpha (transparansi) 0-1

B.6 Properti CSS untuk Latar Belakang

Properti Contoh Nilai Fungsi
background-color red, #ff0000, rgb(255, 0, 0) Mengatur warna latar belakang elemen
background-image url('image.jpg') Mengatur gambar latar belakang elemen
background-repeat repeat, no-repeat, repeat-x, repeat-y Mengatur pengulangan gambar latar belakang
background-position top left, center center, 50% 50% Mengatur posisi gambar latar belakang
background-size auto, cover, contain, 100px 200px Mengatur ukuran gambar latar belakang
background-attachment scroll, fixed, local Mengatur apakah latar belakang ikut digulir atau tetap
background (shorthand semua properti latar belakang) Mengatur semua properti latar belakang sekaligus

B.7 Satuan (unit) dalam CSS

CSS menggunakan berbagai bagian untuk menentukan ukuran. Satuan di bagi menjadi dua kelompok besar:

Unit Kepanjangan Penggunaan
px pixel Unit absolut, 1px = 1 titik pada layar
pt point Unit absolut, 1pt = 1/72 inci
cm centimeter Unit absolut, 1cm = 1/2.54 inci
em em Unit relatif, 1em = ukuran font elemen induk

Unit Referensi Contoh & Keterangan
% Ukuran elemen induk (parent) Unit relatif, 1% = 1/100 dari ukuran elemen induk
em Ukuran font elemen induk Unit relatif, 1em = ukuran font elemen induk
rem Ukuran font root (html) Unit relatif, 1rem = ukuran font elemen root (<html>)
vw Lebar viewport Unit relatif, 1vw = 1% dari lebar viewport
vh Tinggi viewport Unit relatif, 1vh = 1% dari tinggi viewport
vmin Lebar atau tinggi viewport (yang lebih kecil) Unit relatif, 1vmin = 1% dari lebar atau tinggi viewport (yang lebih kecil)
fr Fraksi dari ruang tersedia Unit relatif, digunakan dalam Grid Layout
