materi bab 1

ini adalah h1 berfungsi sebagai judul utama

ini adalah h2 berfungsi sebagai sub judul

ini adalah "<p>" paragraf


ruang kosong di atas ini adalah br untuk membuat baris baru (line break) tag tunggal, tidak memerlukan penutup

garis diatas ini adalah hr untuk membuat garis horizontal sebagai pemisah konten

ini adalah tag <strong> / <b> untuk menebalkan teks

ini adalah tag <em> / <i> untuk miringkan teks

ini adalah tag <span> untuk mengelompokan teks tanpa makna semantik khusus

ini adalah tag <div> elemen blok untuk mengelompokan elemen-elemen html

Gunakan <section> untuk mengelompokkan bagian umum dari suatu halaman atau membagi sebuah artikel menjadi beberapa sub-bagian

Gunakan <article> untuk mengelompokkan konten yang independen dan dapat dijadikan sebagai artikel terpisah

ini adalah judul utama dengan ID yang berfungsi identitas sebuah elemen

ini adalah paragraf dengan class yang berfungsi untuk memberi penanda atau nama kelompok pada satu atau beberapa elemen HTML

ini adalah paragraf dengan style yang berfungsi untuk memberi gaya pada elemen HTML

Atribut id : memberikan identitas unik pada satu elemen

Atribut class : memberikan nama kelas pada elemen (bisa dipakai banyak elemen)

Atribut style : memberikan gaya pada elemen (inline style)

Atribut lang : menentukan bahasa konten

table html

tag keterangan
<table> element induk yang membengkus seluruh tabel
<thead> bagian kepala tabel
<tbody> bagian isi tabel
<tfoot> bagian kaki/footer tabel (optional)
<tr> table row-membuat satu baris dalam tabel
<th> table header cell-sel header (tampilan tebal dan rata sengah secara default)
<td> table data cell-sel data biasa
<colspan> atribut untuk menggabungkan pada kolom menjadi satu
<rowspan> atribut untuk menggabungkan pada baris menjadi satu
